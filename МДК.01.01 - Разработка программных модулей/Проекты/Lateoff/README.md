# Lateoff
>Прилложение Lateoff позволяет отложить выключение или перезагрузку компьютера на выбранное время.
## Функциональность
> Завершение работы

Завершает работу компьютера по истечению выбранного времени.
> Перезагрузка

Перезагружает компьютер по истечению выбранного времени.

> Отмена

Отменяет завершение работы или перезагрузку.
## Инструкция
> Запустить Lateoff.exe

После запуска появится окно в котором нужно выбрать время и завершение работы либо перезагрузку пк.
